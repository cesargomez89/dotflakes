# macOS Setup Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extend dotflakes to support macOS (Apple Silicon) with nix-darwin + Home Manager, mirroring the existing NixOS/GNOME setup.

**Architecture:** Add `nix-darwin`, `nix-homebrew`, `mac-app-util` as flake inputs. Create `darwin/` directory with `base.nix`, `desktop.nix`, and `machines/macbook-pro/`. Update `home-manager/` with conditional logic for macOS vs Linux.

**Tech Stack:** nix-darwin, nix-homebrew, mac-app-util, home-manager, yabai, skhd, Karabiner-Elements

**Files:**
- Modify: `flake.nix`

Add to the `inputs` block:

  url = "github:zhaofengli-wip/nix-homebrew";

  url = "github:hraban/mac-app-util";
  inputs.nixpkgs.follows = "nixpkgs";

**Step 2: Add darwin system variable**

After `system = "x86_64-linux"`, add:
```nix

darwinStdenvHostPlatform = { system = "aarch64-darwin"; };
```

**Step 3: Add darwin pkgs**

After existing pkgs definitions:
```nix
darwinPkgs = import nixpkgs {
  inherit darwinSystem;
  config.allowUnfree = true;
};
```

**Step 4: Add makeDarwinConfiguration helper**

After `makeNixosConfiguration`:
```nix
makeDarwinConfiguration = name: configPath: nix-darwin.lib.darwinSystem {
  system = darwinSystem;
  specialArgs = {
    inherit inputs unstablePkgs llmAgentsPkgs;
  };
  modules = [
    inputs.stylix.darwinModules.stylix
    inputs.mac-app-util.darwinModules.default
    inputs.nix-homebrew.darwinModules.nix-homebrew
    configPath
    home-manager.darwinModules.home-manager
    homeManagerDarwinModule
  ];
};
```

**Step 5: Add homeManagerDarwinModule**

After existing `homeManagerModule`:
```nix
homeManagerDarwinModule = { config, ... }: {
  home-manager.useGlobalPkgs = true;

  home-manager.users.cesar = import ./home-manager/home.nix;
  home-manager.extraSpecialArgs = {
    inherit inputs stylix unstablePkgs llmAgentsPkgs;
    desktopEnv = "darwin";
  };
};
```

**Step 6: Add darwinConfigurations output**

### Task 2: Create darwin/base.nix

**Files:**
- Create: `darwin/base.nix`

Mirrors `nixos/base.nix` for macOS. Key differences:
- No Wayland session variables
- No PipeWire (CoreAudio built-in)
- No systemd, no boot loader
- No services.printing (CUPS built-in)
- No bluetooth service (built-in)
- Use `system.defaults` for macOS preferences
- nix-homebrew configuration
